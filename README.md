# 🎨 Portfólio Desenvolvedor Full Stack

Um portfólio moderno, responsivo e profissional construído com HTML, CSS e JavaScript puro.

## 🚀 Features

- ✅ Design moderno com gradientes e animações
- ✅ Totalmente responsivo (mobile-first)
- ✅ Seções: Hero, Projetos, Habilidades, Contato
- ✅ Animações de scroll suave
- ✅ Cards interativos para projetos
- ✅ Formulário de contato
- ✅ Dark mode (tema escuro)
- ✅ Performance otimizada

## 📁 Estrutura

```
portfolio-dev/
├── index.html       (HTML principal)
├── styles.css       (Estilos modernos)
├── script.js        (Interatividade)
└── README.md        (Este arquivo)
```

## 🛠️ Como usar

1. **Clone ou baixe este repositório**
   ```bash
   git clone https://github.com/seu-usuario/portfolio-dev.git
   cd portfolio-dev
   ```

2. **Edite o `index.html` com suas informações:**
   - Troque "Seu Nome" por seu nome real
   - Atualize os links do GitHub e LinkedIn
   - Adicione seus projetos reais
   - Altere o email e localização

3. **Abra no navegador:**
   - Duplo clique em `index.html`, ou
   - Use um servidor local (Python, Node, etc)

4. **Personalize os estilos em `styles.css`:**
   - Cores (variáveis CSS no topo)
   - Fonts
   - Espaçamentos
   - Breakpoints responsivos

## 📱 Responsividade

O portfólio funciona perfeitamente em:
- Desktop (1920px+)
- Tablet (768px - 1024px)
- Mobile (320px - 767px)

## 📚 Seções

### Hero
Apresentação principal com CTA (Call-to-Action).

### Projetos
Grid de cards com seus projetos. Cada card mostra:
- Título e descrição
- Tecnologias usadas (tags)
- Features principais
- Links para GitHub e Demo

### Habilidades
Grid de categorias de skills:
- Front-end
- Back-end
- Ferramentas
- Conceitos

### Contato
Seção com informações de contato e formulário.
